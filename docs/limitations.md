# 适用范围和未复验的设置

## 论文设定与本项目

本项目独立实现论文第 3 节的模型和损失。训练设置与第 5 节的论文实验存在差异，以下项目影响结果的直接比较。

| 项目 | 当前证据与差异 |
| --- | --- |
| 模型前向 | 默认按论文公式实现，另提供对照源码语义的 `legacy` 模式。两者的激活和 L1 归约不同，详见 [实现审计](implementation_audit.md)。 |
| 合成数据 | 30 维数据构造、噪声和样本数按论文主要实验核对。随机流、种子、缩放流程和搜索网格独立。300 维使用 2,000 行和 3 个种子，计算预算小于论文对应设置。 |
| 真实数据 | California、超导和北京空气质量各使用 4,096 行。California 保留原始计数特征，结果以美元计。北京使用时间顺序划分，风向按序号编码，预测同一时刻的 PM2.5。 |
| 基线 | MLP、Lasso 和简化 NAM。论文中的 SNAM、SPLAM、LassoNet 等其它对照，以及论文 NAM 的完整训练配置，未运行。 |
| 消融 | 通过固定门或移除对应 L1 控制训练变量。额外对照覆盖解冻随机隐藏层与旧实现。固定正则配置的结果应与主实验的验证集搜索结果分别解读。 |
| 计量 | 测试 MSE 同时记录原尺度和缩放尺度。结构分类使用固定门控阈值。没有用真实标签挑阈值，结构分数不等于函数拟合质量。 |

论文正文与作者实现的引用见 [论文](https://doi.org/10.1007/s11704-023-2662-3) 和 [参考代码](https://github.com/BestXuan/NPLAM/tree/73690d3ad9ae8687221775d37c3b4edc478f95a8)。

## 解释边界

- 门控大小是模型参数。它与线性权重之间有尺度不唯一性。用预测误差调参时，预测值接近并不能保证门控可准确恢复结构。
- 三类结构标签依赖已知合成真值和阈值。真实数据上的变量贡献曲线只描述该模型；训练数据的相关性、混杂和覆盖范围限制了外推。
- 稀疏任务和密集任务的 F1 基准不同。密集任务中所有特征都有效，全部选入即可达到 F1=1，因此仍要检查 CF。
- 北京的三次运行共享样本和时间划分。方差主要来自初始化和训练随机性，不能视作三个独立时间窗口的评估。California 的随机划分未评估跨区域泛化，超导数据未按材料家族分组。
- 不同平台、PyTorch 版本和 BLAS 后端可能得到不同的浮点结果。运行清单记录已执行环境，CI 验证的是同一代码的离线可运行性。
